# 经典扫雷 Minesweeper

> 当前版本 **v1.1**（安卓 versionCode 2）

一款用**纯 HTML5 + CSS + JavaScript** 实现的经典扫雷游戏，零依赖、免构建，浏览器直接打开即可游玩，同时提供安卓安装包。

---

## 功能特性

- **三种难度**：初级 9×9·10 雷 / 中级 16×16·40 雷 / 自定义（行·列 5–20、雷数自定）
- **手机端优先**：自定义上限 20×20，格子尺寸按屏幕自适应，任意难度都能完整容纳于一屏
- **像素风素材**：棋盘数字、红色 LED 计数、黄色笑脸、地雷、旗帜等均为独立 PNG 图片，`image-rendering: pixelated` 呈现复古马赛克质感
- **单击 / 长按操作**：Pointer Events 统一鼠标与触摸，手机与桌面同一套交互
- **解题专注**：解题过程中表情始终保持笑脸，仅在胜利 / 失败时切换
- **固定布局**：窗口居中固定，不含拖动 / 缩放手柄

## 操作说明

| 操作 | 效果 |
| ---- | ---- |
| 单击格子（排雷模式） | 翻开该格 |
| 单击格子（插旗模式） | 插旗 / 取消旗 |
| 长按格子（约 0.5 秒） | 插旗 / 取消旗（等效桌面右键） |
| 单击「单击切换：」后的图标 | 切换 排雷 / 插旗 模式 |
| 单击中间表情 | 重新开始 |
| 单击「自定义」难度 | 打开设置弹窗（配置自定义难度） |

> 桌面浏览器中鼠标右键同样可插旗；已用 `touch-action`、`-webkit-tap-highlight-color` 做触控优化。

## 玩法要点

- 翻开数字格，数字表示**周围 8 格**中的地雷数量
- 用旗帜标记你推断有雷的格子
- 翻开所有非雷格子即获胜；踩中地雷即失败
- 第一次点击的格子及其 3×3 邻域**绝不会**有雷

## 运行方式

无需安装、无需构建，浏览器直接打开：

```bash
start minesweeper.html     # Windows
# 或直接双击 minesweeper.html
```

安卓端安装 `minesweeper-v1.1.apk` 即可游玩（debug 签名，可直接侧载）。

## 技术说明

- **零依赖、零构建**：纯原生实现，无需 npm / 打包工具
- **素材管理**：图片路径集中定义在 `assets.js`，便于统一替换
- **首击安全**：第一次点击时才随机布雷，点击格及其周围 3×3 不会有雷
- **泛洪扩散**：翻开空白格时采用递归填充（flood fill）
- **自适应格子**：按屏幕宽高与行列数动态计算 `--cell-size`（最小 12px），保证 20×20 也能完整显示
- **自定义校验**：行 / 列 5–20，雷数 1 至 总格数 − 1，自动修正非法输入
- **安卓图标**：地雷素材（去红底）置于 `#c0c0c0` 灰底
- **安卓封装**：由 Capacitor 打包，详见 `docs/ANDROID_GUIDE.md`
